## 0. ぽにょさんの資料から使う考え方

| 考え方 | このアカウントでの使い方 |
|---|---|
| noteのテーマは「**ちょっと前の自分が悩んでいたこと**の解決策」でいい | さとるが「1〜2年前に悩んでいたこと」＝初デートの沈黙、女性の前の緊張 |
| 大事なのは「すごい実績」より「**同じ悩みを持っていた人がリアルに語ること**」 | 恋愛の達人ではなく「元・暗いやつ」として語る |
| 実績には「数字の実績」と「**努力実績**」がある。努力実績＝調べたこと・やったこと自体が価値になる | 「会話の研究を片っぱしから読んだ」はさとるの努力実績。研究をまとめた記事は、そのまま信頼につながる |
| 構成は「①悩みへの共感 → ②解決できない本当の原因 → ③解決策の全体像 → ④具体的な手順 → ⑤まとめ＋応援」 | 有料noteはこの形。無料noteは①②③までにして、④は有料noteへ |
| 無料部分の最後は、有料パートの目次を**コピーライティング＋虫食い（●●●）**にする | 無料noteの最後に、本命noteの中身を「答えだけ隠した目次」で見せる |
| Threadsは「日常3割・教育5割・セールス1〜2割」。教育ポストは「理想・恐怖・共感」の3つの型 | Threadsの投稿プランに使う（14のファイル） |
| 上から目線・「教えてあげる」感はNG。同じ目線で、自分の体験から語る | さとるの口調ルールと同じ |

## 1. メインペルソナ：ゆうと（恋愛の悩み）

### プロフィール
| 項目 | 内容 |
|---|---|
| 名前（仮） | ゆうと |
| 年齢 | 26歳 |
| 仕事 | 会社員（事務・技術系。社内の人と話すのは、なんとかなる） |
| 住まい | 一人暮らし |
| 恋愛 | 学生時代に少しだけ付き合ったことがある、または交際経験なし |
| 今の状況 | マッチングアプリを始めて2〜3か月。メッセージは続くこともあるが、会うと続かない |
| よく使うSNS | Threads、YouTube、X（見る専門） |
| スマホを見る時間 | 通勤中、昼休み、寝る前の布団の中 |

### 読者の今の状態（ぽにょさんの「読者の今の状態」）
- 初デートが決まると、うれしいより先に**「沈黙したらどうしよう」**が来る
- 前回のデートは、カフェで1時間。一問一答で終わり、2回目に誘えなかった
- デートの前の夜に「初デート 話題」「沈黙 気まずい」を検索している
- 話題リストをスマホにメモしていくが、当日は**相手が答えたあとが続かない**
- 帰り道はひとり反省会。お礼のメッセージの返信を何度も確認してしまう
- 友達には「考えすぎだよ」と言われるけど、どう考えなければいいのかがわからない

### 悩み（表の悩み／本当の悩み）
| 表の悩み（口に出す言葉） | 本当の悩み（心の中） |
|---|---|
| 会話のネタが欲しい | 緊張していても「次に何を言えばいいか」が出てくるようになりたい |
| 沈黙をなくしたい | 沈黙が来ても、焦らない自分になりたい |
| モテたい | 「この人と話すの楽しい」と思われたい。2回目につなげたい |
| 話し上手になりたい | 話し上手じゃなくても大丈夫だと知りたい |
| — | **「自分は恋愛に向いてないのかも」と思い始めていて、それが一番こわい** |

### 読者がなりたい姿（ぽにょさんの「読者がなりたい姿」）
- 初デートで、相手が答えたあとに自然と次の言葉が出てくる
- 沈黙が来ても「あ、ここはあれだな」と落ち着いていられる
- 帰り道に「今日、楽しかったな」と思える
- 2回目のデートに、自然に誘える

### すでに試して、うまくいかなかったこと
- 「初デート 話題〇選」の記事やYouTube → 最初の一言しか使えなかった
- 質問リストをメモ → 一問一答になって、面接みたいになった
- 「沈黙は気にしなくていい」というアドバイス → 気になるものは気になる
- 場数を踏む → 失敗の記憶が増えただけ

### 刺さる言葉／刺さらない言葉
| 刺さる | 刺さらない（むしろ離れる） |
|---|---|
| 会話が続かない／沈黙が怖い／頭が真っ白／一問一答／へぇ〜で終わる／ひとり反省会／2回目がない | モテテク／落とす／必ず／100％／オラオラ系の言い方 |
| あなたのせいじゃない／やり方を知らなかっただけ | 「コミュ力を上げろ」「自信を持て」（できないから困っている） |
| 元・暗いやつ／僕もそうだった | 恋愛の達人・成功者目線 |

### 買う決め手になるもの
1. 書いている人が「自分と同じだった」こと（さとるの過去）
2. 覚えることが少なく、**当日そのまま使える**こと（型・カンペ）
3. ちゃんと根拠があること（研究）
4. 価格が、デート1回のカフェ代＋α くらいであること

## 3. ペルソナから決めた「書き方のルール」

1. **最初の1行は、ゆうと（またはけんた）が「今まさに」いる場面から始める**（例：デート前夜の検索、商談前の検索）
2. **答えより先に「あなたのせいじゃない」を言う**
3. **さとるの体験は「同じ目線」で**（「教えてあげる」ではなく「僕もそうだった」）
4. **研究は「ちゃんと調べた努力実績」として出す**（ただし難しく書かない）
5. **無料noteの最後は、本命noteの「虫食い目次」で終わる**
