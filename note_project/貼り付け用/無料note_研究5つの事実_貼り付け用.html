タイトル：会話が苦手な人ほど信じている「5つの思い込み」｜心理学の研究でわかった、仕事でもデートでも効く話

「忙しそうだから、話しかけないでおこう」
「沈黙したってことは、相手は退屈してるんだ」
「ほめたいけど、気持ち悪いと思われそう」

会話が苦手な人ほど、こんなふうに考えて、ひと言を飲み込んでしまいます。

でも実は、これ、ほとんどが思い込みなんです。

しかも、ただの気休めじゃありません。心理学の研究で、ちゃんと確かめられています。

このnoteでは、会話が苦手な人が信じがちな5つの思い込みと、それをくつがえした研究を、むずかしい言葉なしで紹介します。

職場でも、取引先でも、デートでも。読み終わるころには、「あ、話しかけてもいいんだ」と、ひと言目が少し軽くなっているはずです。5分くらいで読めます。

まずは「思い込み度」をチェック

あてはまるものは、いくつありますか？

  • □ 相手が忙しそうだと、話しかけるのをやめてしまう
  • □ 沈黙が来ると、「相手は退屈してるんだ」と思う
  • □ ほめたいことがあっても、照れくさくて言えない
  • □ 店員さんや受付の人とは、必要なこと以外話さない
  • □ 「深い話は、相手に迷惑だろう」と思う

3つ以上あてはまったら、この先の5つの研究が、たぶんあなたの考え方を変えます。

そもそも、なんで研究なのか

はじめまして、さとるです。高校では「口数の少ない、暗いやつ」。社会人2年目の初デートは、ボロボロでした。

（くわしい話は、最後にリンクを貼った自己紹介に書いています）

会話を学び直すとき、僕は「こう言えばいい」というテクニックの前に、人はどんなときに相手と仲良くなるのかという「しくみ」を知りたくて、心理学の研究を片っぱしから読みました。

そこで一番おどろいたのが、会話が苦手な人の悩みの多くは、「思い込み」から始まっているということでした。

今日は、その思い込みを5つ、ひっくり返していきます。

思い込み① 「相手は、自分と話したくないだろう」

シカゴ大学の研究者が、通勤電車でこんな実験をしました。※1

「となりの知らない人に話しかける」グループと、「ひとりで静かに過ごす」グループ。別の通勤客たちに「どっちが快適だと思う？」と聞くと、多くの人が「ひとりのほうが快適」と予想しました。

ところが、結果は逆。話しかけたほうが、ずっと楽しい時間になったんです。

なぜ予想がはずれたのか。それは、みんな「相手は自分と話したくないだろう」と思い込んでいたから。実際は、話しかけられた側も、けっこううれしかったんです。

  • 仕事だと：「忙しそうだから」と遠慮している相手も、ひと息つける雑談を待っているかもしれない
  • デートだと：相手も、あなたのことを知りたくてその場に来ている

思い込み② 「沈黙は、相手が退屈しているサイン」

ハーバード大学などの研究チームが、900回以上の会話を調べて、こんなことを確かめました。※2

会話は、2人が「ここで終わりたい」と思ったタイミングで終わることは、ほとんどない。

そしてもう1つ。人は、相手が「いつ会話を終わらせたいと思っているか」を、ほとんど当てられなかったんです。

つまり、あなたが「沈黙したから、相手はもう帰りたいんだ」と思っても、それはたいていただの当てずっぽう。

ちなみに研究者によると、「早く終わりたい」人と「もっと話したい」人は、だいたい同じくらいいたそうです。

沈黙＝退屈、と決めつけなくていいんです。

  • 仕事だと：商談のあとの沈黙。相手は「早く帰りたい」のではなく、次の話を待っているだけかもしれない
  • デートだと：カフェでの数秒の沈黙。それだけで「つまらなかったんだ」と落ち込まなくていい

思い込み③ 「ほめたら、気持ち悪いと思われる」

「そのネクタイ、いいですね」
「その考え方、すてきですね」

心の中で思っても、口に出せない。照れくさいし、変に思われそう。

シカゴ大学の研究では、9つの実験で、こんなことがわかっています。※3

ほめる側は、

  • 相手がどれくらい喜ぶかを、実際より低く見積もっていた
  • 相手がどれくらい気まずく感じるかを、実際より高く見積もっていた

つまり、ほめ言葉は、あなたが思うよりずっと喜ばれて、ずっと気まずくない。

しかも、「うまく言わなきゃ」と言い方を気にするより、「相手を思う気持ち」に目を向けた人のほうが、ほめやすくなったそうです。

  • 仕事だと：同僚の資料の「ここ、わかりやすいですね」のひと言で、関係がやわらかくなる
  • デートだと：「そのお店選び、センスいいですね」は、照れずに言っていい

思い込み④ 「必要なこと以外は、話さなくていい」

コーヒーショップで、こんな実験がありました。※4

レジで、

  • 店員さんにほほえんで、目を見て、ちょっとだけ会話をした人
  • できるだけ手早く、必要なことだけで済ませた人

結果は、ちょっと会話をした人のほうが、気分が良くなっていた。しかも、「自分はここにいていいんだ」というつながりの感覚も強くなっていたんです。

別の研究では、大学生がいつもより多くのクラスメイトと話した日は、幸せな気持ちが高かったこともわかっています。※5 親友じゃなくても、ちょっとした知り合いとの会話で、気持ちは変わるんです。

  • 仕事だと：エレベーターでの「今日、寒いですね」は、ムダな時間じゃない
  • デートだと：デートの日以外に、店員さんとのひと言で「話す練習」ができる

思い込み⑤ 「深い話は、相手に迷惑」

天気の話、仕事の話。当たりさわりのない話だけで終わっていませんか？

別の研究では、初対面どうしで、ちょっと踏み込んだ話（たとえば「最近、一番感謝したことは？」）をしてもらいました。※6 すると、本人たちの予想よりずっと気まずくならず、むしろ仲良くなれたんです。

人は「深い話なんて、相手は嫌がるだろう」と心配しすぎている。これも、思い込みでした。

  • 仕事だと：業界ニュースの話から、一歩だけ「相手自身の話」に踏み込むと、相手の顔がパッと明るくなることがある
  • デートだと：天気の話で終わらせず、一歩だけ踏み込んだほうが、会話は弾みやすい

5つの思い込みが外れると、どうなるか

並べると、こうなります。

1. 相手も、本当は話したいと思っている
2. 沈黙は、退屈のサインとは限らない
3. ほめ言葉は、思うよりずっと喜ばれる
4. ちょっとした会話にも、ちゃんと意味がある
5. 少し深い話は、思ったより気まずくない

ここまで読んで、「話しかけてもいいんだ」と少し思えたなら、それがこのnoteのゴールです。

……ただ、正直に言うと。

思い込みが外れても、最後にもう1つ壁が残ります。

「じゃあ、話しかけたあと、何を言えばいいの？」

相手が答えてくれた。そのあとに、何を返すか。
沈黙が来た。そのときに、何をするか。

ここは「思い込み」ではなく、「やり方」の話です。

「話しかけたあと」のやり方は、こちらにまとめました

さいごに

会話が苦手な人は、相手に迷惑をかけたくない人です。

だからこそ、「話しかけないほうがいい」「ほめないほうがいい」と、ひと言を飲み込んでしまう。

でも、今日の研究のとおり、そのひと言は、あなたが思うよりずっと、相手にとってうれしいものです。
