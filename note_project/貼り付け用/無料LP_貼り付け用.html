僕がそうでした。会話の本や動画であんなに勉強したのに、初デートでは「へぇ〜……」のあと、何も出てこなかった。

  • なぜ、沈黙がこんなに怖いのか

読み終わるころには、「自分がダメなんじゃなかったんだ」と、少し肩の力が抜けているはずです。5分くらいで読めます。

あてはまるものは、いくつありますか？

  • □ 相手の答えに「へぇ〜」「そうなんですね」しか返せない
  • □ 相手が自分の知らない話をすると、固まってしまう

さっきのチェック、実は僕はほとんどあてはまっていました。

僕は中学でいじめられて、人と話すのが怖くなりました。高校では「口数の少ない、暗いやつ」。周りからも、そんなふうに扱われていました。

大学生のころに初めて友達ができて、本や動画で会話の勉強もしました。ふだんの会話は、少しずつできるようになった。

でも、女性の前に立つと、やっぱりダメでした。

社会人2年目。マッチングアプリで出会った女性との初デートは、カフェでした。

相手が好きなものの話をしてくれたのに、僕はまったく返せなかった。そこから先は、一問一答。沈黙が怖くてずっとあたふたして、相手が気をつかって話を振ってくれても、心ここにあらず。

ゆっくりすることもなく解散して、次に誘う勇気も出なくて。連絡は、自然と途絶えました。

「大学生のころから、あんなに勉強してきたのに」

正直、かなり落ち込みました。

どうして、話題リストだけじゃダメなのか

会話が続かなくて悩んでいる人ほど、ちゃんと努力しています。

  • 「初デートで盛り上がる話題〇選」を読んで、ネタをメモした
  • 質問リストを、スマホに保存していった
  • 「沈黙なんて気にしなくていいよ」というアドバイスを信じてみた
  • とにかく場数を踏めば慣れるはずだ、と思った

でも、うまくいかなかった。

それは、あなたの努力が足りなかったからじゃありません。

話題や質問のリストは、「最初の一言」しか教えてくれないからです。

相手が答えてくれた、その「次」に何を言えばいいのか。そこは、どのリストにも書いていない。だから、せっかく用意した質問を1つ使ったら、また「へぇ〜……」に戻ってしまう。

「沈黙を気にするな」と言われても、気になるものは気になる。

やり方を知らないまま回数だけ増やしても、増えるのは失敗の記憶だけ。

僕も、本や動画であんなに勉強したのに、初デートではまったく役に立ちませんでした。

先に、これだけは知っておいてほしいんです

ここで、あなたに伝えたいことがあります。

沈黙が怖いのは、あなたが弱いからじゃない

人って、会話がたった4秒止まるだけで、「拒否された」ような気持ちになる生き物なんです。※1

だから、沈黙で焦るのは当たり前。人間なら、誰でもそうなります。

しかも、日本人が沈黙を「気まずい」と感じ始めるのは、だいたい7.8秒くらいから。世界の平均より長くて、日本人はむしろ沈黙に強いほうなんです。※2

あなたが「やばい！」と焦っているその3秒。相手はたぶん、そこまで気にしていません。

慣れていないのは、あなただけじゃない

20代の独身男性の約4割は、デートをしたことがありません。※3

そして、相手のデート経験が多いか少ないかを、女性の約7割は「気にならない」と答えています。※4

「慣れてないのがバレたら終わり」は、ほとんどの場合、思い込みです。

でも、会話だけは、ちゃんと見られている

ただ、ひとつだけ現実の話もさせてください。

2回目のデートで気持ちが冷めた理由を聞いた調査では、1位は「会話が弾まない」でした。※5

見た目でも、お店選びでもなく、会話。

つまり、裏を返せば、会話さえ変われば、2回目は変わるということです。

僕に足りなかったのは、才能じゃなかった

初デートで落ち込んだあと、僕はもう一度、会話を学び直しました。

今度は「女性との会話」「初デートの会話」に絞って、本や動画、それから「人はどんな会話で仲良くなるのか」を調べた心理学の研究まで、片っぱしから読みました。

そこで、やっとわかったんです。

僕に足りなかったのは、

  • 面白い話をする才能でも
  • たくさんの話題でも
  • 女性と話した経験の数でもなかった

足りなかったのは、「相手が答えたあとの、次の一手」と、「沈黙が来たときの、決めごと」。

たった、それだけでした。

チェックした項目ごとに、答えがある場所はこうなっています。

  • 「へぇ〜」しか返せない
    → 覚えるのはたった1つ。会話が自然に続く「基本の型」
  • 知らない話で固まる
    → 知らない話こそチャンスに変わる「ひと言」
  • 一問一答・面接みたいになる／自分の話ばかりしてしまう
    → 聞きすぎず、話しすぎない「ちょうどいいバランス」
  • 用意した質問をうまく使えない
    → 待ち合わせ／食事中／解散前で使える「場面別の質問テンプレート」
  • 沈黙で頭が真っ白になる
    → 考えなくても体が動く、沈黙したときの「もしもプラン」4つ
  • デート前に緊張する
    → 待ち合わせ前につぶやく「ひと言」
  • 帰り道のひとり反省会
    → 落ち込まずに次につなげる「振り返り方」
  • 次のデートに誘えない
    → 2回目に自然につなげる「タイミング」

どれも、僕が学んで、試して、失敗して、やっと「これなら使える」と思えたものだけです。

話し上手になる必要はありません。 覚えることも、本当に少しだけ。スクショしてスマホに入れておける「当日のカンペ」もつけています。

途中までは無料で読めるので、まずはのぞいてみてください。

こんな人に読んでほしい

  • 初デートが決まって、正直ちょっと不安な人
  • 「何を話すか」より、「相手が答えたあとが続かない」のが悩みの人
  • 話し上手になりたいわけじゃない。沈黙が怖くなくなれば十分、という人
  • 相手に「今日、楽しかった」と思って帰ってもらいたい人

逆に、女性を思いどおりに動かすテクニックを知りたい人には、向いていません。僕が書いているのは、相手も自分も楽しくなるための会話です。
