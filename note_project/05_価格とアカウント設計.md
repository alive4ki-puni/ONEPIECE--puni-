## 2. 価格の提案

### 競合の価格（note・男性向けの初デート会話）
- 480円：初デート全体のガイド（有料部分 約1万字）
- 980円：初デートの質問集（21選）
- 980円：初デートの会話の続け方
- 2,490円：同じ著者の恋愛記事をまとめた有料マガジン

→ **単品は480〜980円が中心**。1,000円を超える単品は少ない。
（出典：note上の各記事。2026年10月時点の検索結果。価格は変わることがあります）

### このnoteの強み（競合より高くできる理由）
1. 質問リストではなく「質問のあとをどうするか」まで答えている
2. 根拠のある方法だけを使い、出典がついている（競合ではほぼ見かけない）
3. 沈黙したときの「もしもプラン」、Q&A、当日カンペまである
4. 本文は約1.2万字で、そのうち有料部分は約6,000字

### このnoteの弱み（今はまだ高くしにくい理由）
1. 新しいアカウントなので、実績・フォロワー・レビューがない
2. 【体験の追記】がまだ埋まっていない

### 結論：市場価値は「1,480円」。ただし最初は980円から

| 段階 | 価格 | いつ | 狙い |
|---|---|---|---|
| ① 発売直後 | **980円** | 最初の30部くらいまで | 競合と同じ価格で、まず買ってもらう。感想をもらう |
| ② 通常価格 | **1,480円** | 感想が3〜5件集まったら | このnoteの本来の価値。競合より少し高いが、中身の量と根拠で納得してもらえる |
| ③ 上限の目安 | 1,980円 | フォロワーが増え、感想が10件以上たまったら | 単品ではここが限界。これ以上は、上位版やマガジンで売る |

**値上げの告知について**
「〇部売れたら1,480円に値上げします」と書くのはOKです。ただし、**本当に値上げする場合だけ**にしてください。値上げしないのに書くと、ウソの宣伝になってしまいます。

| パターン | 必要な数（月） |

| 1,480円の単品だけ | 約68部（1日2〜3部） |
| 1,480円 ＋ 上位版4,980円（購入者の2割が買う） | 約40部 ＋ 上位版8部 |
| 上の2つ ＋ 月額マガジン980円（30人） | 約30部 ＋ 上位版6部 ＋ マガジン30人 |

※ noteの手数料（決済手数料・プラットフォーム利用料）が引かれるので、手取りはこれより少なくなります。最新の手数料はnoteの公式ヘルプで確認してください。

## 3. アカウント設計

### キャラクターの軸
> **「もともと話すのが苦手。学んで、試して、たくさん失敗して、やっと沈黙が怖くなくなった人」**
> 読者より“ちょっとだけ先”を歩いている先輩。上から教える先生ではなく、隣で「こうしたらうまくいったよ」と教えてくれる人。

| 項目 | 設定 |
|---|---|
| 立ち位置 | 恋愛の達人ではない。「元コミュ障の、ちょっと先輩」 |
| 強み | 苦手な人の気持ちがわかる／失敗談を隠さない／ちゃんと調べてから話す |
| 口調 | です・ます調。ときどき「〜なんですよね」「わかります」。えらそうにしない |
| 一人称 | 僕 |
| 読者の呼び方 | あなた |

### 名前の案
- **沈黙ニガテだった〇〇｜元コミュ障の会話ノート**
- **〇〇｜話すのが苦手だった僕の恋愛メモ**
- **〇〇@沈黙が怖かった人**

（〇〇には、呼ばれやすい短いニックネームを入れてください）

### プロフィール文の案

**note用（長め）**
```
もともと人と話すのが本当に苦手でした。
初デートでは沈黙して頭が真っ白、帰り道はひとり反省会。

そこから会話のやり方を学んで、試して、失敗して。
今も話し上手ではないけれど、沈黙はもう怖くなくなりました。

このアカウントでは、
「会話が苦手な人でも、今日から使えるやり方」だけを書いています。
・初デートの会話
・沈黙したときの立て直し方
・2回目のデートにつなげるコツ

むずかしいテクニックや、相手を操る方法は書きません。
「相手も自分も、ちょっと楽しかった」と思える会話を一緒に練習しましょう。
```

**X・Threads用（短め・160字以内）**
```
元コミュ障。初デートで沈黙して、帰り道ひとり反省会してた人｜学んで・試して・失敗して、沈黙が怖くなくなりました｜会話が苦手な男性向けに「今日から使える会話の型」を発信中｜相手を操るテクより、お互い楽しい会話を｜初デートが不安な人は固定のnoteへ
```

### プロフィールに書かないこと
- 「デート〇〇回」「彼女〇人」のような、**本当じゃない数字**
- 「モテる」「落とせる」「100%」のような言葉（キャラクターと合わない／信用を失う）
- 恋愛の資格や肩書き（持っていない場合）

### 実際の数字を入れると強くなるところ（本当のことだけ）
- 何年くらい会話が苦手だったか
- 初デートで失敗した回数（だいたいでOK）
- 変われたと感じたきっかけ

→ 本当の数字が1つ入るだけで、プロフィールの信頼感はかなり上がります。

### 発信の柱（Threads・Xで毎日投稿するネタ）
| 柱 | 割合 | 例 |
|---|---|---|
| ① 失敗談 | 3割 | 「初デートで『へぇ〜』しか言えなかった日の話」 |
| ② すぐ使える一言 | 4割 | 「知らない話が来たら『教えてください』でOK」 |
| ③ 気持ちが楽になる話 | 2割 | 「相手は、あなたが思うより楽しんでいたかもしれない」 |
| ④ noteの案内 | 1割 | 「初デートが不安な人向けにまとめました」＋リンク |

**ポイント**：毎日の投稿で「この人の話、わかりやすいし役に立つ」と思ってもらう。そのうえで、ときどきnoteを案内する。案内ばかりだと読まれなくなります。

### 失敗談のネタ帳（オーナーが本当にあったことを書きためる場所）
- [ ] 初デートで一番気まずかった沈黙
- [ ] 質問攻めにして、相手が疲れていた日
- [ ] 自分の話ばかりしてしまった日
- [ ] 初めて会話が続いて「楽しかった」と言われた日
- [ ] 2回目のデートに誘えなかった日／誘えた日

→ ここが埋まるほど、noteの【体験の追記】、毎日の投稿、次のnoteのネタになります。
