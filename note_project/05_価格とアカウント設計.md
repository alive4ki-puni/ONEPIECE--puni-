## 2. 価格の提案

→ **単品は480〜980円が中心**。1,000円を超える単品は少ない。
（出典：note上の各記事。2026年10月時点の検索結果。価格は変わることがあります）

### このnoteの強み（競合より高くできる理由）
1. 質問リストではなく「質問のあとをどうするか」まで答えている
2. 根拠のある方法だけを使い、出典がついている（競合ではほぼ見かけない）
3. 沈黙したときの「もしもプラン」、Q&A、当日カンペまである
4. 本文は約1.2万字で、そのうち有料部分は約6,000字

### このnoteの弱み（今はまだ高くしにくい理由）
1. 新しいアカウントなので、実績・フォロワー・レビューがない
2. 【体験の追記】がまだ埋まっていない

### 結論：市場価値は「1,480円」。ただし最初は980円から

| 段階 | 価格 | いつ | 狙い |
|---|---|---|---|
| ① 発売直後 | **980円** | 最初の30部くらいまで | 競合と同じ価格で、まず買ってもらう。感想をもらう |
| ② 通常価格 | **1,480円** | 感想が3〜5件集まったら | このnoteの本来の価値。競合より少し高いが、中身の量と根拠で納得してもらえる |
| ③ 上限の目安 | 1,980円 | フォロワーが増え、感想が10件以上たまったら | 単品ではここが限界。これ以上は、上位版やマガジンで売る |

**値上げの告知について**
「〇部売れたら1,480円に値上げします」と書くのはOKです。ただし、**本当に値上げする場合だけ**にしてください。値上げしないのに書くと、ウソの宣伝になってしまいます。

### キャラクターの軸

※くわしい年表と書くときのルールは「00_キャラクター設定シート_正本.md」が正解です。ここと食い違ったら、正本に合わせてください。

読者より“ちょっとだけ先”を歩いている先輩。恋愛の達人でも先生でもない。
「僕にできたんだから、あなたにもできるよ」と、隣で言ってくれる人。

| 項目 | 設定 |

| 転機① | 大学で初めて友達ができ、会話を勉強し始める。会話が少し楽しくなる |
| 転機② | 社会人になっても女性の前では緊張。マッチングアプリの初デートがボロボロ → もう一度学び直す |

| 一人称／読者の呼び方 | 僕／あなた |

### 「僕が学んで、実践したこと」の設定
キャラクターが「何を学んで克服したのか」を、noteの中身と同じ形でそろえます。これが**発信の中身そのもの**になります。

| 順番 | 学んだこと | 中身（noteのどこにあるか） | 克服できた悩み |
|---|---|---|---|
| ① | 沈黙が怖いのは、自分のせいじゃない | 人は4秒の沈黙で不安になる。日本人はむしろ沈黙に強い（第2章） | 「自分はダメだ」という思い込み |
| ② | 面白い話はしなくていい | 人は自分の話を聞いてもらうのが好き。質問する人ほど好かれる（第2章） | 「盛り上げなきゃ」というプレッシャー |
| ③ | 1つ聞いて、2つ深掘り | 「きっかけは？」「たとえば？」「どうだった？」の3つの言葉（STEP1） | 質問のあとが続かない |
| ④ | 知らない話は「教えてください」 | 知っているフリをせず、素直に聞く（STEP1） | 知らない話題が来るとパニックになる |
| ⑤ | 受け止める一言を挟む | 「いいですね！」「〇〇ですか！」（STEP1） | 質問が取り調べっぽくなる |
| ⑥ | 聞いたら、自分も少し話す | 深掘り2回で、自分の話を1つ（STEP2） | 質問攻めで面接みたいになる |
| ⑦ | 沈黙したときの「もしもプラン」 | 目の前のもの／さっきの話に戻る／自分から答える／正直に言う（STEP4） | 沈黙した瞬間に固まる |
| ⑧ | 緊張は「楽しみになってきた」に言い換える | （STEP0） | デート前の緊張で頭が真っ白 |
| ⑨ | 振り返りは「よかったこと3つ、直すこと1つ」 | （STEP5） | 帰り道のひとり反省会で落ち込む |

### いじめの話の扱い方（大事）
- **プロフィールと、noteの「はじめに」で触れるくらいにとどめる**。毎日の投稿で何度も使うと、「不幸話で売っている」と見られやすくなります
- 書くのは「つらかった」「人と話すのが怖くなった」まで。**いじめた相手を特定できる話や、悪口は書かない**
- 書くのがつらくなったら、無理に書かなくて大丈夫。「コミュ障と言われていた」だけでも十分伝わります
- 読者の中にも、同じ経験をした人がいるかもしれません。「あなたも悪くない」というやさしい目線で書く

### プロフィールに書かないこと
- 「デート〇〇回」「彼女〇人」のような、**本当じゃない数字**
- 「モテる」「落とせる」「100%」のような言葉（キャラクターと合わない／信用を失う）
- 恋愛の資格や肩書き（持っていない場合）
- 彼女が特定できる情報（名前・写真・職場など）

### 実際の話を入れると強くなるところ（本当のことだけ）
- 何歳くらいまで「コミュ障」と言われていたか
- 何を最初に学んだか（本、動画、人から教わった など）
- 初デートで失敗した回数（だいたいでOK）
- 彼女とは、どんな会話がきっかけで仲良くなったか

→ 1つでも本当の話が入ると、プロフィールとnoteの信頼感がぐっと上がります。
