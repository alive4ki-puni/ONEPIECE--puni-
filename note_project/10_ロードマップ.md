## 2. ゴールと逆算

### 最終ゴール：月10万円
1,480円の本命noteだけなら、月に約68部。

**もし本命noteを読んだ人の2％が買うとすると**（※仮の数字です。実際の購入率は、売れ始めてから計算し直す）
→ 68部 ÷ 2％ ＝ **本命noteを月3,400回読まれる**必要がある

これを、本命note1本だけでやるのは大変です。だから、
- 入口（Threads・無料note）を増やして、読まれる回数を増やす
- 2本目の有料note、セット販売、上位版で、**1人あたりの売上**を上げる

の2つを同時に進めます。

> ⚠️ 月10万円は、半年〜1年かけて目指す目標です。最初の1〜2か月は「売上」より「読まれる数・フォロワー・感想」を育てる時期と考えてください。

## 3. ロードマップ

### フェーズ0：土台づくり（今週 10/24〜10/31）
**目的：お客さんが来たときに、迷わず本命noteまでたどり着ける状態にする**

- [ ] **Threadsのアカウントを作る**（名前・プロフィール文・アイコンは「07_プロフィール文と画像プロンプト.md」のとおり）
- [ ] Threadsのプロフィールのリンク欄に、**本命noteのURL**を入れる
- [ ] noteのクリエイターページで、**自己紹介noteを「固定」**にする（一番読まれ、一番スキがついている記事なので、入口にする）
- [ ] 3つのnoteの「（ここに〜のリンクを貼る）」が、全部本物のリンクになっているか確認する
- [ ] 本命noteの価格が**980円**になっているか確認する
- [ ] Threadsで最初の投稿：**自己紹介の短い版**（「中学でいじめ→暗いやつ→初デートはボロボロ→彼女ができた」）

### フェーズ1：入口を育てる（11月・1か月目）
**目的：Threadsで「この人の話、わかる」と思ってもらい、noteに来てもらう**

**毎日やること**
- Threadsに**1日2〜3投稿**
  | 種類 | 割合 | 例 |
  |---|---|---|
  | さとるの失敗談 | 3割 | 「初デートで『へぇ〜』しか言えなかった日の話」 |
  | すぐ使える一言（※有料noteの答えは出さない） | 4割 | 「質問は『〜ですか？』より『どんな〜？』」 |
  | 気持ちが楽になる話 | 2割 | 「沈黙が怖いのは、あなたが弱いからじゃない」 |
  | noteの案内 | 1割 | 「初デートが不安な人へ。全部まとめました」＋リンク |
- 同じ悩みを持つ人の投稿に、**本音でコメントする**（1日3〜5件。宣伝はしない）

**毎週やること**
- noteの**無料記事を週1〜2本**（ネタは下の「無料記事のネタ」から）
- 記事の最後に、無料LP・本命noteへのリンクを入れる
- 日曜日にダッシュボードを見て、下の「チェックする数字」を記録する

## 6. やらないこと

- 同じ内容の宣伝投稿を何度もくり返すこと
