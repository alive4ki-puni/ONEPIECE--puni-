## 2. 投稿のバランス（ぽにょさんの資料どおり）

| 種類 | 割合 | 目的 | このアカウントでの中身 |
|---|---|---|---|
| **日常ポスト** | 3割 | 「この人、親しみやすいな」 | コーヒー、おいしいもの、マンガ、彼女との会話が楽しいこと（※正本にある事実だけ）＋読者への問いかけ |
| **教育ポスト** | 5割 | 「この人の話、もっと知りたい」 | 3つの型で書く ↓ |
| 　└ 理想の型 | | 「いいな、私もそうなりたい」 | 会話が楽しくなった今の様子 |
| 　└ 恐怖の型 | | 「知らないと損してる」 | 話題リストだけでは足りない、沈黙の思い込み など |
| 　└ 共感の型 | | 「この人の過去、自分と同じだ」 | 暗いやつ時代、ボロボロの初デート |
| **セールスポスト** | 1〜2割 | noteの存在に気づいてもらう | 「買ってください」は絶対NG。自然に「noteにまとめました」 |

### 投稿のルール
- 1投稿 **100〜300字**（Threadsの上限は500字。短いほうが読まれやすい）
- **1行目で止める**：読者が「自分のことだ」と思う言葉から始める
- 最後に**問いかけ**を入れて、コメントしやすくする（日常・共感ポスト）
- **有料noteの答えは出さない**（3つの言葉、もしもプラン②〜④、場面別テンプレート、緊張のひと言、振り返り方）
- AIの文章をそのまま使わず、**さとる自身の言葉を少し足してから**投稿する
- **作った体験は書かない**。「今日〇〇した」は、本当にあった日だけ

### 投稿の時間（ゆうとがスマホを見る時間）
| 時間 | ねらい |
|---|---|
| 7:00〜8:00 | 通勤中 |
| 12:00〜13:00 | 昼休み |
| 21:00〜23:00 | 寝る前（いちばん悩みが深くなる時間） |

→ 最初は **1日2投稿（朝 or 昼に1つ、夜に1つ）** から。慣れたら3投稿に

## 4. 投稿文（1週目・14本）

### ① 固定投稿：自己紹介
```
はじめまして、さとるです。

中学でいじめられて、人と話すのが怖くなりました。
高校では「口数の少ない、暗いやつ」。
社会人2年目の初デートは、ボロボロ。

そこから会話を学び直して、試して、たくさん失敗して。
今は、そんな僕にも彼女がいます。

ここでは、会話が苦手だった僕が見つけた
「今日から使える小さなコツ」を発信します。

会話が続かない人、沈黙がこわい人。
よかったら、仲良くしてください😊
```

### ② 共感：初デートの「へぇ〜……」
```
「休みの日って何してるんですか？」
「映画とか見てますね」
「へぇ〜……」

……で、沈黙。

これ、昔の僕です。
質問はできるのに、相手が答えたあとが続かない。

頭の中は「次なに話そう」でぐるぐる。
帰り道はひとり反省会。

同じ経験ある人、いませんか？
```

### ③ 日常：コーヒー
```
最近、家でコーヒーを淹れるのにハマってます☕

ゆっくりお湯を注いでる時間が、けっこう好きで。
昔は人と話したあと、ひとり反省会ばっかりしてたので、
こういう「ほっとする時間」を大事にしたいなと思ってます。

みなさんは、ほっとする時間ってありますか？
```

### ④ 恐怖の型：話題リストだけでは足りない
```
初デートの前に「盛り上がる話題」を検索してる人へ。

正直に言います。
話題リストを覚えるだけだと、当日また沈黙するかもしれません。

リストが教えてくれるのは「最初の一言」だけ。
相手が答えてくれた、その「次」は、どこにも書いてないんです。

僕はこれに気づくまで、ずっと同じ失敗をくり返してました。
```

### ⑤ 共感の型：暗いやつ時代
```
高校のころの僕は、クラスで「口数の少ない、暗いやつ」でした。

誰も話しかけてこないし、自分からも話しかけられない。
休み時間は、ひとりで勉強。
教科書とはだいぶ仲良くなりました（人間とは、まったく）。

あのころの自分に言いたい。
「才能がないんじゃない。やり方を知らなかっただけだよ」って。
```

### ⑥ 理想の型：会話が楽しいと思えた日
```
会話を学び直して、しばらくたったころのデート。

何を話したかは、正直よく覚えてません。
でも「あ、今キャッチボールできてる」って、初めて感じたんです。

帰り道、ひとり反省会じゃなくて
「初対面の人と話すのって、楽しいんだ」って思えた。

あの感覚は、たぶん一生忘れません。
```

### ⑦ 日常：おいしいもの
```
おいしいものを食べるのが好きです🍜

おいしいものって、それだけで話題を1つくれるのがいいですよね。
「これ、おいしいですね」って、誰とでも言える最強の一言だと思ってます。

最近食べて、おいしかったもの教えてください！
```

### ⑧ 恐怖の型：4秒の沈黙
```
会話が4秒止まるだけで、
人は「拒否された」ような気持ちになるらしいです。
（オランダの大学の実験より）

だから、沈黙で焦るのは当たり前。
あなたの心が弱いからじゃない。

ちなみに日本人は、世界的に見ると沈黙に強いほう。
あなたが焦ってる3秒、相手はたぶん気にしてません。
```

### ⑨ 教育：「どんな？」で聞く
```
会話が一問一答で終わる人へ。

「お仕事、忙しいですか？」
→「まあまあです」で終わる。

「お仕事って、どんな感じなんですか？」
→ 相手が自分の言葉で話してくれる。

「はい・いいえ」で答えられる質問は、そこで会話が止まりやすいんです。
語尾を「どんな？」「何を？」に変えるだけで、けっこう変わりますよ。
```

### ⑩ セールス（パターンA：悩みに寄り添う→note）
```
「沈黙が怖くて、初デートが楽しめない」
そんな相談をもらうことが増えました。

わかります。僕もずっとそうでした。

沈黙が怖くなくなるまでに、僕が学んで、試して、
失敗して見つけたやり方を、noteに全部まとめています。

プロフィールのリンクから読めます。
途中までは無料なので、よかったらのぞいてみてください。
```
※「相談をもらうことが増えました」は、**実際に相談が来てから**使う。来ていなければ1行目を「沈黙が怖くて、初デートが楽しめない。」に変える

### ⑪ 日常：マンガ
```
少年マンガが好きです📚

実は、今の彼女と仲良くなったきっかけもマンガでした。
休みの日の話をしてたら、同じマンガが好きだとわかって、
気づいたら時間を忘れて話してました。

会話が2往復で止まってた僕が、です。

みなさんの「人生で一番ハマったマンガ」、教えてください！
```

### ⑫ 共感の型：一問一答のカフェ
```
社会人2年目、マッチングアプリの初デート。
場所はカフェでした。

相手が好きなものの話をしてくれたのに、僕は何も返せなかった。
そこから先は、ずっと一問一答。

相手が気をつかって話を振ってくれても、心ここにあらず。
次に誘う勇気も出なくて、連絡は自然と途絶えました。

あの日が、学び直すきっかけになりました。
```

### ⑬ 教育：相手は思ったより好意的
```
会話のあと「つまらないと思われたかも…」と落ち込む人へ。

人は初対面の会話のあと、
「相手にどう思われたか」を実際より悪く考えるクセがあるそうです。

自分の失敗ばかり気になって、
相手が笑ってくれたことを見落としてしまう。

帰り道のひとり反省会、たぶん考えすぎです。
```

### ⑭ セールス（パターンB：体験→プロフィール）
```
「暗いやつ」と言われてた僕に、彼女ができるまで。

中学のいじめ、高校の「暗いやつ」時代、
ボロボロだった初デート、学び直した日々。

全部、noteの自己紹介に書きました。
同じように会話で悩んでる人に、届いたらうれしいです。

プロフィールからどうぞ。
```

## 5. 投稿ネタを増やすときのプロンプト（ぽにょさんの資料をこのアカウント用に記入）

### 日常ポスト
```
あなたはThreadsで「会話が苦手な人のためのコミュニケーション」をテーマに発信しているアカウントの運用アドバイザーです。

以下の条件で、フォロワーとの距離が縮まるような「日常ポスト」のネタを10個考えてください。

【発信テーマ】会話が苦手な人の、初デート・職場の会話
【ターゲット】会話が続かない・沈黙が怖い20〜30代の男性
【私のキャラクター】中学でいじめられ、高校では「暗いやつ」。社会人2年目の初デートはボロボロ。会話を学び直して、今は彼女がいる。趣味は家でコーヒーを淹れること、おいしいものを食べること、少年マンガ

条件：
- テーマに関連した日常の小さな出来事や気づきの投稿にすること
- 読者が思わずコメントしたくなるような「問いかけ」や「あるあるネタ」を入れること
- 上から目線やイキった表現は絶対NG。親しみやすく、距離が近い文体で
- 絵文字は1〜2個まで
- 1投稿あたり100〜200文字くらい
- 実際にそのまま投稿できるレベルの文章で出力すること
```

### 教育ポスト
```
あなたはThreadsで「会話が苦手な人のためのコミュニケーション」をテーマに発信しているアカウントの運用アドバイザーです。

以下の3つの型で、教育ポストのネタをそれぞれ5個ずつ（合計15個）考えてください。

【発信テーマ】会話が苦手な人の、初デート・職場の会話
【ターゲット】会話が続かない・沈黙が怖い20〜30代の男性
【私のキャラクター】（日常ポストと同じ）
【販売しているnoteの内容】初デートの沈黙が怖くなくなる「魔法の質問テンプレート」。研究で裏付けた5ステップ

■ 型1：理想の状態を見せるポスト（5個）
■ 型2：恐怖を煽るポスト（5個）※「知らないと損」と気づかせる。ただし不安をあおりすぎない
■ 型3：共感ポスト（5個）

条件：
- 上から目線の「教えてあげる」感は絶対NG
- あくまで自分の体験ベースで、同じ目線から語る
- noteの有料部分の答え（質問の型、深掘りの言葉、沈黙したときの対処法）は書かない
- 1投稿あたり150〜300文字くらい
- 実際にそのまま投稿できるレベルの文章で出力すること
```

※ AIが出した体験談は、**正本にない出来事なら使わない**。使う前に必ず正本と照らし合わせる
