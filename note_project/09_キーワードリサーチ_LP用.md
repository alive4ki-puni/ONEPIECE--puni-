# キーワードリサーチ（無料LP用）

調査日：2026-10-24
調べた場所：Yahoo!知恵袋、note、恋愛・婚活メディアの記事、アンケート調査の報道

---

## 1. 読者が実際に使っている「悩みの言葉」

ターゲット（会話が苦手な20〜30代の男性・初デート前後）が、検索や相談で使っている言葉です。**LPの見出しや本文には、この言葉をそのまま使います。**

| 分類 | 刺さる言葉 | よく出てくる場面 |
|---|---|---|
| いちばん大きい悩み | **会話が続かない**／**沈黙が怖い**／**沈黙が気まずい** | 検索・相談でいちばん多い |
| 頭の中 | **何を話せばいいかわからない**／**頭が真っ白**／**焦る** | 緊張の相談 |
| 会話の形 | **一問一答**／**質問攻め**／**面接みたい** | 「質問しても一問一答で終わる」という悩み |
| ネタ | **ネタ切れ**／**話題が尽きる**／**話題が見つからない** | 準備しても当日つまる |
| 返し | **「へぇ〜」で終わる**／**話が広がらない** | 相手の答えのあとが続かない |
| 緊張 | **女性の前だと緊張する**／**男同士なら話せるのに** | 「男同士だと緊張しないのに」という悩み |
| デートのあと | **ひとり反省会**／**つまらない男だと思われた**／**返信が来ない** | 帰り道 |
| 一番こわい結果 | **2回目がない**／**次に誘えない**／**自然消滅** | 「二度目はない」 |

## 2. 読者が「本当に欲しいもの」（当事者の立場で考えた）

| 表の願い | その奥にある本当の願い |
|---|---|
| 会話のネタが欲しい | **「次に何を言えばいいか」が、緊張していても出てくるようになりたい** |
| 沈黙をなくしたい | **沈黙が来ても、焦らない自分になりたい** |
| モテたい | **「この人と話すの楽しい」と思ってもらいたい。2回目につなげたい** |
| 話し上手になりたい | **話し上手じゃなくても大丈夫だと知りたい** |
| 失敗したくない | **「自分がダメなんだ」と思わなくていい理由が欲しい** |

**→ LPで渡すもの**：「わかってもらえた」という安心感／「自分のせいじゃない」という理由／「変われる」という希望（さとるの実例）／「自分がどのタイプか」がわかる気づき
**→ LPで渡さないもの**：具体的なやり方（型・質問・返し方・沈黙の対処）。これは有料noteで受け取る

## 3. 読者がすでに試して、うまくいかなかったこと

| 試したこと | うまくいかない理由（LPではここまで言う。解決策は言わない） |
|---|---|
| 「話題〇選」「質問リスト」を読んだ | 質問は用意できても、**相手が答えた「その次」**は誰も教えてくれない |
| 話すネタを準備していった | 準備したネタを話すことに必死で、**相手の話を聞けなくなる** |
| 「沈黙を気にするな」と言われた | 気にするなと言われても、**気になるものは気になる** |
| 場数を踏もうとした | やり方を知らないまま回数だけ増えると、**失敗の記憶が増えるだけ** |

## 4. LPで使うデータ（不安をやわらげる／現実を知る）

| データ | 使い方 | 出典 |
|---|---|---|
| 会話が4秒止まるだけで「拒否された」気持ちになる | 「沈黙が怖いのは脳のしくみ」 | Koudenburgら（2011） |
| 日本人が沈黙を気まずいと感じるのは約7.8秒から（世界平均より長い） | 「あなたの3秒は、相手にとって事件じゃない」 | Preply（2024年、21か国・29,538人） |
| 20代独身男性の約4割はデート経験なし | 「あなたは少数派じゃない」 | 内閣府 令和4年版 男女共同参画白書 |
| 女性の約7割は、相手のデート経験を気にしない | 「慣れてなさは、バレても大丈夫」 | IBJ（2022年、557人） |
| 2回目のデートで冷めた理由の1位は「会話が弾まない」（17％） | 「会話は、2回目があるかどうかを左右する」 | マイナビニュース（2024年5月）の調査記事 |

> ⚠️ 「2回目で冷めた理由」のデータは、回答者の男女の内訳を確認できていません。LPでは「2回目のデートで冷めた理由を聞いた調査では」と書き、「女性が断る理由」とは書かないこと。

## 5. タイトルの考え方
- 「会話が続かない」「沈黙が怖い」の2つは必ず入れる（いちばん検索されやすく、いちばん刺さる）
- 「あなたのせいじゃない」で、責められる不安を先に消す
- さとるの立場（元・暗いやつ）を入れて、「この人はわかってくれそう」と思ってもらう
