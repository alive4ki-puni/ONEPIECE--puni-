## 3. 書くときのルール（ブレ防止）

### 必ず守ること
| 項目 | ルール |
|---|---|
| 人と話すのが怖くなった時期 | **中学から**。「生まれつき」「ずっと昔から」とは書かない（小学生のころは普通に話せていた） |
| 「コミュ障」 | 高校のころ、周りからそう扱われていた。自分から名乗っていたわけではない（他称） |
| 学んだ回数 | **2回**。大学生のころに1回目、社会人2年目の初デートで失敗してから2回目（学び直し） |
| 学んだ方法 | **本と動画で、自分で勉強した**（2回目は心理学の研究も）。**大学の授業や学問として学んだわけではない**。「大学で学んだ」とは書かず、「大学生のころに自分で勉強した」と書く。特定の本や人の名前は出さない |
| 彼女 | マッチングアプリで出会った。きっかけは共通のマンガの話。マンガのタイトルや彼女の情報は出さない |
| 大学のころ | 友達はできた。会話も少し楽しくなった。でも**女性の前の緊張はまだ残っていた** |
| 初デート | マッチングアプリで出会った女性との初デートが「ボロボロ」だった |
| 今 | 彼女がいる。話し上手ではないが、沈黙は怖くない |
| 一人称／読者の呼び方 | 僕／あなた |
| 口調 | です・ます調。ときどき「〜なんですよね」「わかります」。えらそうにしない |

### 書かないこと
- 本当じゃない数字（デートの回数、付き合った人数など）
- 「モテる」「落とせる」「100%」「必ず」
- いじめた相手が特定できる話、悪口
- 彼女や、デートした女性が特定できる情報（名前・写真・職場・住んでいる場所）
- 恋愛の資格や肩書き（持っていないもの）

### 気をつける話題
| 話題 | 扱い方 |
|---|---|
| いじめ | 自己紹介noteと本命noteの「はじめに」くらいにとどめる。毎日の投稿で何度も使わない |
| 親への八つ当たり | 自己紹介noteでだけ触れる。「今思うと最低だった」という反省とセットで書く |
| マッチングアプリの女性で練習した話 | 「練習台にした」とは書かない。「一回一回のデートで、学んだことを試させてもらっていた。今思えば相手に失礼だったかもしれない。だからこそ、毎回相手に楽しんでもらえるように…」と、**反省と相手への敬意**をセットで書く |
