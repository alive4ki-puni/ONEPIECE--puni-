## 第1部　全記事に共通する「売れるLPの骨組み」

6本すべてが、次の流れでできています。順番が入れ替わることはあっても、要素はほぼ全部入っています。

| # | 要素 | 役割 | ぽにょさんの例 |
|---|---|---|---|
| 1 | **つかみ（代弁・逆張り・暴露）** | 1行目で止める | 「もうXで勝つのは厳しいですか？」「一緒に頑張ろうね…こんな運用のヤバさに気づいてますか…？」「白状します」 |
| 2 | **読む理由の予告** | 離脱を防ぐ | 「この記事を読み終わった頃には〜悩みが吹き飛ぶ」「5分くらいでサクッと読める」 |
| 3 | **読者の悩みの箇条書き** | 「自分のことだ」と思わせる | 「SNS発信を始めたけどなかなか稼げない…」×3 |
| 4 | **自分の過去（どん底）** | 共感・信頼 | 手取り14万、貯金10万で脱サラ、50万円のスクール |
| 5 | **原因の断言（〜だけ）** | 「自分のせいじゃない」＋「簡単に直せそう」 | 「単に"事例を知らない"だけ」「あなたが自分の商品を持っていないから。はい、シンプルですね」 |
| 6 | **放置したときの損（損失回避）** | 今やらなきゃと思わせる | 「この状態は加速していく」「500円を取りこぼし続ける方がよっぽど怖い」 |
| 7 | **反論処理** | 「でもそれって…」を先につぶす | 「ぽにょさんは実績あるからでしょ？って、そう思う？」 |
| 8 | **再現性・社会的証明** | 「自分にもできる」 | 「実績も何もない40代男性が1か月で7万円」「人柄やキャラではない」 |
| 9 | **理想の未来の体感描写** | 欲しくさせる | 「ピロン…！！［記事購入のお知らせ］×5」「愛犬と散歩してる間に購入通知」 |
| 10 | **答えの手前で止める（〇〇で伏せる）** | 続きを買わせる | 「稼ぐために必要なのは〇〇。これだけです。これ以上はネタバレになるので言えません」 |
| 11 | **CTA（行動の呼びかけ）＋限定性** | 今すぐ動かす | 「今だけ無料」「記事は予告なく公開停止する場合があります」「段階的に値上げ」 |
| 12 | **締め（ポジティブ・笑い・p.s.）** | 好感を残す | 「ではでは〜」「p.s. 徹夜で誤字ってたら笑っとくれ」 |

## 第2部　記事ごとの構成分析

### ① Myペルソナ（自己紹介型LP）＝いちばん大事
**構成（見出しそのものがストーリーの段階になっている）**
1. 変化前の日常：限界社畜の悲鳴
2. 行動開始：勢いで脱サラ
3. 変化1：貯金ゼロの極貧下積み時代
4. 変化2：月収1000万円越えの世界
5. 不安（いいことばかりじゃない）
6. 転機：“ある人”の教材との出会い
7. 理想の状態：暇すぎる世界
8. 呼びかけ：好きなことを発信して、本当に自由な人生を目指しませんか
9. 告知（CTA）

**感情曲線（上下させているのがポイント）**
```
理想 ────────────────────────────────●（暇すぎる世界）
                        ●（月200万）              
              ●（初収益1万）     ＼               ／
●（社畜）─●（脱サラ）   ／          ●（不安・労働）
          ＼          ／
            ●（50万スクール・1日1食）＝どん底
```
→ 一直線に成功させず、**「上がる→落ちる→もっと上がる」**をくり返す。ぽにょさん自身が別記事で「感情曲線」と呼んでいる

**テクニック**
| テクニック | 例 | 効果 |
|---|---|---|
| **数字で生活を見せる** | 24歳、手取り14万、貯金50万以下、家賃6万、朝6時起床・7時出発・23時帰宅 | 読者が「自分と同じ」と一瞬で重なる |
| **五感の描写** | 満員電車に揺られ／胃がキリキリ／カップ麺／死んだように寝る | 映像が浮かぶ |
| **心の声をカッコで** | 「昨日はめちゃくちゃ叱られたな…」（自分もそのひとりか…） | 本音が聞こえる |
| **箇条書き＋ユーモア** | 給料が少ない／残業が多い／上司がうるさい／**社長の頭が禿げてる** | 重い話の中で笑わせて読ませる |
| **小さな願望** | 愛犬と1日過ごしたい、朝は優雅に紅茶を飲みたい、あと3万円あれば | 読者の「本当はこうしたい」と重なる |
| **社会的な不安** | 大企業でも終身雇用は保障されない、年金ももらえるかわからない | 「このままじゃダメ」を自分ごとにする |
| **失敗を隠さない** | 怪しいDM→30分後に50万円をクレカで | 信頼が増す。「この人は本当のことを言う」 |
| **名言化** | 0→1が一番むずかしい。1円稼げたら1000円稼げる… | 記憶に残る・引用される |
| **気づきの言語化** | 環境を変えた→付き合う人が変わった→性格が変わった | 読者に考え方を渡す |
| **擬音で体感させる** | ピロン…！！［記事購入のお知らせ］×5 | 理想の未来を「体験」させる |
| **最後に主張** | ネットの“自由な生活”はハリボテが多い／才能はマジで不要。学んでやるか、やらないか | 立場をはっきりさせる |

### ② ポスト作成思考（教育LP）
**構成**：実績のチラ見せ（3日で100人増・日給9万）→ 記事の目的（コラムとしてサラッと）→ 実例ポスト4本を「本文→解説」の順で → 次の告知 → 感想の依頼

**ここで公開されているポストの作り方（そのまま使える）**
| 法則 | 内容 |
|---|---|
| **導入は代弁** | 読者が思っていることをそのまま1行目に（「もうXで勝つのは厳しいですか？」） |
| **疑問を残す** | 結論を先に言うが理由は言わない（「結論、まだまだ余裕です」→なんで？） |
| **損失回避ワード** | 「誤解だらけの〇〇の裏側」→「自分も間違ってる？」と不安にさせる |
| **PREP法** | 結論→理由→具体例→結論 |
| **余裕を見せる比喩** | 「ボーナスステージ」「マリオのスター状態」 |
| **放置の危険を訴える** | 「この状態は今後どんどん加速していく」 |
| **反論処理** | 「主張すると読者は何て言う？」を考えて先に答える |
| **再現性** | 「人柄やキャラではない」と言い切る |
| **悩みの箇条書き→原因は「〜だけ」→具体例3つ→「才能じゃない、知らないだけ」→導線** | 文脈のある誘導。バズらせてリンクを貼るだけでは売れない |
| **導線は2〜3日に1回** | 「固定ポスト見てみて」の一言がないと読者は動かない |
| **限定性の一言** | 「あとで読む」は9割読まれない |
| **言葉の印象まで考える** | 「愛のムチを打つ」→「愛のムチをｽﾊﾟﾝｽﾊﾟﾝと撃ち続ける」 |
| **幸せの基準を普通に** | 2人で5000円のお寿司の投稿＝親近感 |
| **ポジティブで締める** | 「雨で体調も悪い」より「雨だけど楽しもう」 |
| **現状を下げつつ、可能性を褒める** | 「え、痩せたら絶対可愛いよね！？もったいないし頑張ろうよ」 |

### ③ ブランディング戦略（逆張り主張型）
**構成**：逆張りタイトル（〇〇〇〇〇は自分の首を絞めます）→「この先、口が悪くなります」と前置き（好奇心）→ 読者の声（社会的証明）→ 過去の悩み → 問いかけ「そんな状況で続けられますか？」→「違いとは…」で引っ張って答え → 解決策（優しさの中にトゲ）→ 注意点2つ → **読者に考えさせる間（・・・5秒止めて考えて）** → まとめ（POINT）→ 弊害を正直に（オチで笑い）

**法則**
- **主張は尖らせる、言葉は尖らせない**：「1日2ポストもできないなら、会社員のほうが楽」→合わない人が自然に離れる＝**買う前にふるいにかける**
- **強さにはストーリーを乗せる**：「愛犬が心臓病になって、治療費を稼ぐしかなかった」→強さの理由に共感が生まれる
- **寄り添いすぎは危険**：「一緒に頑張ろうね」だけだと、厄介なお客さんまで集まる

### ④ そりゃ稼げなくて当たり前です（問題指摘型）
**構成**：1文字ずつ縦に並べた「ま・さ・か」→ 悩み3つ → 名前をつける（「ゴミ運用と呼びます（呼びません）」）→ 今の自分の状況（バスタオル1枚で執筆）＝臨場感 → 読了後のベネフィットと時間 → 小さなエピソード（フォローしてきた人のプロフ）→ 原因の断言 → たとえ話（パンを焼かずに集客するパン屋）→ 事例 → 具体的なネタ例 → 損失（500円の取りこぼし）→ 自分の過去（当時の自分をぶん殴りたい）→ 最悪の未来 → 反論（どうやって作ればいいかわからない、ですよね）→ CTA

**法則**
- **たとえ話で「当たり前」を気づかせる**（パン屋・カフェ）
- **具体的すぎるネタ例**を出して「そんなのでいいの？」を壊す
- **「失うものは何もない」**で行動のハードルを下げる

### ⑤ 白状します（暴露型）
**構成**：暴露タイトル → 2つの暴露を予告 → 意外な告白（実は1日1〜2時間しか働いていない）→ リアルなタイムスケジュール → 自虐 → それでも稼げる（ギャップ）→「なぜ？」→ やっていないことリスト → **「必要なのは〇〇。これ以上はネタバレ」** → 紹介 → 特典 → 受け取り方3ステップ → p.s.

**法則**
- **自虐とギャップ**：ダメな部分を見せるほど、成果が際立つ
- **「何をやるか」より「何をやらないか」**
- **〇〇で伏せて止める**

### ⑥ バイブル本（紹介型）
**法則**
- **「最後に紹介するのがダントツ」と先に言う**→最後まで読ませる
- **ランキング＋1行の理由**で読みやすく
- **読者のリクエストに応えた形**にする（「おすすめ知りたいです！と言われたので」）

| 分類 | ぽにょさんの技 | 例 |

## 第4部　さとるのアカウントで「使うもの／使わないもの」

### ✅ そのまま使う（さとるのキャラ・これまでのルールと合う）
| 法則 | さとる版の例 |
|---|---|
| Myペルソナ型の段階見出し＋感情曲線 | 自己紹介noteを「変化前の日常：口数の少ない暗いやつ」→「行動開始：大学で初めての友達」→「変化1：会話が少し楽しくなった」→「どん底：社会人2年目、ボロボロの初デート」→「転機：学び直し」→「理想の状態：沈黙が怖くない世界」に作り直す |
| 数字と五感で生活を見せる | ※さとるの本当の数字が必要（下の「質問」） |
| 心の声をカッコで | すでに使っている（（やばい、次なに話そう）など） |
| 導入は代弁 | 「初デートの前に『話題』を検索していませんか？」（無料LPで採用済み） |
| 疑問を残す | 「結論、話題リストはいりません」→なんで？ |
| 誤解だらけの〇〇の裏側 | 「誤解だらけの“初デートの会話術”の裏側」 |
| 原因は「〜だけ」 | 「会話が続かないのは、単に“相手が答えたあとの一言”を知らないだけ」 |
| 反論処理 | 「それって、もともと話せる人の話でしょ？って思う？　僕、高校では『暗いやつ』でしたよ」 |
| 再現性を言い切る | 「話のうまさや性格じゃない。知っているかどうか、それだけ」 |
| 答えの手前で〇〇で伏せる | 無料noteの虫食い目次（13で採用済み） |
| 主張を尖らせる（言葉は尖らせない） | 「話題リストを暗記する時間があるなら、相手の話を聞く練習をしたほうがいい」「相手を操るテクを知りたい人には、僕のnoteは向いてません」 |
| 強さにストーリーを乗せる | 「いじめで人と話すのが怖くなった僕だから、言えることがある」 |
| 幸せの基準を普通に | コーヒー、おいしいもの、マンガ、彼女とのなにげない会話 |
| ポジティブで締める | 投稿の最後は前向きな一言 |
| 導線は2〜3日に1回 | Threadsの投稿プランに反映（セールスは1〜2割） |
| 名言化 | 「会話は、才能じゃない。やり方だ」 |
| 「最後がいちばん大事」と先に言う | 「5つの事実のうち、最後の1つがいちばん効きます」 |

### ⚠️ 条件つきで使う（本当のときだけ）
| 法則 | 条件 |
|---|---|
| 限定性（今だけ・予告なく公開停止・段階的に値上げ） | **本当にそうするときだけ**。値上げは「感想が5件集まったら1,480円にします」のように、実際の予定として書く |
| 反応を取るCTA（反応した人だけに送る） | 実際に送る特典があるときだけ |
| 社会的証明（読者の声） | 本当にもらった感想を、本人の許可を取って使う |
| 実績の数字 | 本当の数字だけ。盛らない |

### ❌ 使わない（さとるのキャラや信用と合わない）
| 法則 | 理由 |
|---|---|
| 「嫌悪感なく煽る」「現状を貶す」の強いもの | さとるの読者は、すでに自信をなくしている人。強く下げると離れる。下げるより「あなたのせいじゃない」で寄り添う |
| 作業時間や実績の誇張ネタ | 本命noteは「言いすぎない」が信頼の土台 |
| オラオラ・無双感の比喩（マリオのスター状態など） | 「元・暗いやつ」と合わない。代わりに「僕でもできた」の安心感で勝負する |
| 稼ぐ系の言葉 | ジャンルが恋愛・会話なので不要 |

## 第5部　さとる版「売れるnote」の型（まとめ）

```
【タイトル】読者の悩み（代弁）＋意外な主張 or 疑問
　例：初デートの話題リスト、もう覚えなくていいです｜元「暗いやつ」の僕が気づいた、会話が続く人の共通点

【つかみ】読者が今している行動・思っていることを1行目で代弁

【予告】読み終わると何が手に入るか＋何分で読めるか

【悩みの箇条書き】チェックリスト

【さとるの過去】数字・五感・心の声で（感情曲線を下げる）

【原因の断言】「〜だけ」で、才能のせいじゃないと言い切る

【反論処理】「それって〇〇でしょ？って思う？」

【放置したときの損】このままだと2回目がない、あきらめグセがつく

【気づき・名言】会話は才能じゃない、やり方だ

【理想の体感描写】帰り道、スマホに「今日楽しかったです」と届く（※読者の未来の想像として書く）

【答えの手前で止める】虫食い目次（●●●）

【CTA】本命noteへ。限定性は本当のときだけ

【締め】ポジティブ＋さとるらしい一言
```
