## 2. プロフィール文

### 考え方
パッと見て、この4つが伝わるようにしています。

| 伝えること | プロフィール文のどこ |
|---|---|
| どんな人？ | 中学でいじめ → 高校で「暗いやつ」→ 初デートはボロボロ |
| 何をしてる？ | 会話のコツを発信している |
| 誰のため？ | 会話が続かない・沈黙がこわい人 |
| どんな未来？ | 「話すのって楽しい」に変わる。彼女ができた僕が見本 |

### Threads用（113字）
```
中学でいじめ、高校では「暗いやつ」。
初デートはボロボロ。
そんな僕にも、彼女ができました。

会話が続かない。沈黙がこわい。
そんなあなたが「話すのって楽しい」に変わる、小さなコツを毎日発信中。

▼初デートの沈黙がこわくなくなるnote
```
- プロフィールのリンク欄には、**本命noteのURL**を入れます
- 文字数の上限は公式には確認できませんでした。短めに作ってあるので、たぶん大丈夫ですが、入らない場合は最後の1行を消してください

### note用（103字）
```
中学でいじめられ、高校では「暗いやつ」。社会人になっても、初デートはボロボロ。そんな僕が会話を学び直して、彼女ができました。会話が続かない、沈黙がこわい人へ。「話すのって楽しい」に変わるコツを書いています。
```
- noteの自己紹介欄は、公式ヘルプで「140文字以内」とされているので、その中に収めています
- くわしい話は、自己紹介noteにまかせます。自己紹介noteは、クリエイターページの「固定記事」にしておくのがおすすめです

### プロフィール文で使っている言葉のルール（ブレ防止）
| 使う言葉 | 使わない言葉 |
|---|---|
| 会話が続かない／沈黙がこわい | コミュ力アップ／モテる |
| 話すのって楽しい | 落とせる／必ず／100% |
| 小さなコツ／今日から使える | テクニック／裏ワザ |
| 暗いやつ（高校のころ） | 生まれつき／ずっと（小学生は普通に話せていたため） |

## 3. キャラクターの見た目（固定設定）

アイコンも見出し画像も、**同じキャラクター・同じ色**で作ります。毎回このブロックをプロンプトに入れてください。

| 項目 | 設定 |
|---|---|
| キャラクター | 20代の男の子。2〜3頭身のデフォルメ |
| 顔 | 丸い顔、小さな点の目、ちょっと照れたほっぺの赤み、やさしい笑顔 |
| 髪 | 黒髪、少しボサッとした短髪。前髪が少し目にかかる |
| 服 | 無地のオレンジのパーカー |
| 小物 | 白い吹き出し（**中は空っぽ・文字なし**）＝「会話」のシンボル |
| 色 | メイン：やさしいオレンジ（#F4A261）／背景：クリーム（#FFF4E0）／線・アクセント：こげ茶（#4A3B32） |
| 絵のタッチ | 太めでやわらかい線、フラットな塗り、影は少なめ、シンプル |

**キャラクターの性格の出し方**：自信満々ではなく、「ちょっと照れながらも、がんばってる」感じ。読者が「自分に近い」と思える見た目にします。

## 4. アイコン画像のプロンプト（ChatGPT用）

### サイズ
- 正方形（1:1）で作る。ChatGPTでは 1024×1024 でOK
- Threadsもnoteも**丸く切り取られて表示**されるので、キャラクターは真ん中に、まわりに余白を多めにとる

### プロンプト
```
SNSのプロフィールアイコン用のイラストを作ってください。

【キャラクター】
・20代の日本人の男の子を、2〜3頭身にデフォルメしたキャラクター
・丸い顔、小さな点の目、ほっぺに少し赤み、ちょっと照れたやさしい笑顔
・黒髪で、少しボサッとした短髪。前髪が少し目にかかっている
・無地のやさしいオレンジ色（#F4A261）のパーカーを着ている
・片手を胸の前で小さく振っていて、「はじめまして」と照れながらあいさつしている雰囲気

【小物】
・キャラクターの頭の横に、白くて丸い吹き出しを1つ。吹き出しの中は空っぽ

【背景】
・クリーム色（#FFF4E0）の無地

【絵のタッチ】
・太めでやわらかい線（こげ茶色 #4A3B32）、フラットな塗り、影は少なめ
・シンプルで愛嬌があり、小さく表示されてもひと目でわかるデザイン

【構図】
・正方形。丸く切り取られても顔と吹き出しが欠けないよう、キャラクターを中央に、上半身だけを大きめに配置し、周りに余白をとる

【禁止】
・文字、数字、ロゴ、記号は一切入れない（吹き出しの中も空白）
・リアルな絵柄、細かすぎる描き込み、ごちゃごちゃした背景
```

### うまくいかないときの追加の指示
- 文字が入ってしまった → 「吹き出しの中も含めて、文字を完全に消してください」
- 顔が小さい → 「顔をもっと大きく、画面の中央にしてください」
- 大人っぽすぎる → 「もっと丸くて、ゆるキャラっぽくしてください」

## 5. noteの見出し画像（アイキャッチ）

### サイズ
- **1280×670ピクセル**（note公式ヘルプの推奨サイズ。横長、だいたい1.91：1）
- サイズが違うと、自動で切り取られて表示されます。大事なもの（キャラクターの顔）は**真ん中**に置き、上下と左右の端には何も置かないようにします

### 作り方の流れ
1. 上のアイコンを先に作る
2. ChatGPTで、**できたアイコン画像を添付して**「このキャラクターと同じ見た目で」と伝える（キャラクターがブレにくくなります）
3. ChatGPTは横長だと 1536×1024 で出てくるので、Canvaなどで **1280×670 に切り取る**
4. タイトル文字を入れたい場合は、Canvaで入れる（AIに日本語を書かせると、文字が崩れやすいため）

### ① 本命note用：「初デートの沈黙が怖くなくなる魔法の質問テンプレート」

**伝えたいこと**：沈黙で困っていた → 会話が続いて笑顔に

```
noteの記事の見出し画像を作ってください。添付したキャラクターと、まったく同じ見た目・同じ絵のタッチで描いてください。

【場面】
・カフェのテーブルに、キャラクターが座っている（相手は描かない）
・キャラクターの頭の上に、白くて丸い吹き出しが3つ、ポンポンと続いて浮かんでいる（会話が続いているイメージ）。吹き出しの中は空っぽ
・キャラクターは、ちょっと照れながらもうれしそうな笑顔
・テーブルの上には、コーヒーカップが2つだけ

【色】
・背景はクリーム色（#FFF4E0）の無地。テーブルはうすい木の色
・キャラクターのパーカーはオレンジ（#F4A261）。全体の色数は少なく

【構図】
・横長（横3：縦2）
・キャラクターと吹き出しは、画面の真ん中に寄せる。上下・左右の端には何も置かず、余白を広くとる（あとで横長に切り取るため）

【絵のタッチ】
・太めでやわらかい線（#4A3B32）、フラットな塗り、影は少なめ、シンプルで目を引く

【禁止】
・文字、数字、ロゴは一切入れない（吹き出しの中も空白）

```

**Canvaで文字を入れるなら（任意）**
- 大きく：「沈黙が、こわくなくなる。」
- 小さく：「初デートの魔法の質問テンプレート」
- 文字は左右どちらかの余白に置き、キャラクターに重ねない

## 6. 今後の見出し画像のルール（ブレ防止）
- キャラクターは毎回**同じアイコン画像を添付**して作る
- 色は**オレンジ・クリーム・こげ茶**の3色が基本。増やしても1色まで
- 「白い吹き出し（中は空っぽ）」を毎回どこかに入れる＝このアカウントの目印
- 女性（彼女やデート相手）は描かない。描く場合も後ろ姿やシルエットだけにする（特定されないため）
- 文字はAIに書かせず、必要ならCanvaで入れる
