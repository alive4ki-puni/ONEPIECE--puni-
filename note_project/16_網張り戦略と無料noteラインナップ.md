作成日：2026-10-28
> キャラクター設定は「00_キャラクター設定シート_正本.md」、売れる型は「15_ぽにょ式LP分析と売れるnoteの法則.md」が正解。

## 1. 考え方：2種類の読者を、1つの網でつかまえる

| 読者 | 呼び方 | 状態 | どこで見つけてもらうか | 最初に読ませる記事 |
|---|---|---|---|---|
| **会話が苦手だと自覚している人** | 顕在層（既知の人） | 「会話が続かない」「沈黙が怖い」と自分で検索している | 「初デート 会話」「沈黙 気まずい」などで検索／Threads | 共感・体験の記事 |
| **自覚していないけど、同じ悩みを持っている人** | 潜在層（未知の人） | 「職場の雑談」「アイスブレイク」「1on1」など、別の言葉で悩んでいる | 仕事・人間関係の言葉で検索／note内のおすすめ | 「実は同じ悩みだった」と気づかせる記事 |

**割合の目安：顕在層7：潜在層3**
顕在層の記事で「この人の話、わかる」と信頼を貯めて、潜在層の記事で新しい人を連れてくる。潜在層の人は、網をたどって顕在層の記事へ、そして本命noteへ進む。

---

## 2. 網の全体図

```
                        ┌──────────────────┐
                        │ 本命note（有料）     │ ← ゴール
                        └──────────────────┘
                          ↑        ↑        ↑
          ┌───────────────┘        │        └───────────────┐
          │                        │                        │
  ┌───────────────┐       ┌────────────────┐       ┌────────────────┐
  │ 無料LP           │ ←→  │ 自己紹介（ハブ）    │ ←→  │ 顕在層の記事たち    │
  │（話題リスト）      │       │ 固定記事・全記事から │       │ E1〜E5            │
  └───────────────┘       │ リンクされる       │       └────────────────┘
          ↑                └────────────────┘                ↑
          │                        ↑                          │
          └────────────┬───────────┴──────────┬───────────────┘
                       │                      │
              ┌─────────────────┐   ┌─────────────────┐
              │ 5つの思い込み      │ ←→│ 潜在層の記事たち    │
              │（潜在層の玄関）     │   │ L2〜L5            │
              └─────────────────┘   └─────────────────┘
                       ↑                      ↑
                 検索・note内のおすすめ・Threads（新しい人が入ってくる）
```

**流れのルール**
- 潜在層の記事 → 「5つの思い込み」や顕在層の記事 → 本命note（いきなり有料に飛ばさず、1段はさむ）
- 顕在層の記事 → 本命note（虫食い目次でしっかり誘導）
- どの記事からも → 自己紹介（ハブ）へ。自己紹介からは全部の記事へ行ける

## 5. リンクの張り方ルール

### 1本の記事に入れるリンク（最低3本、多くても6本）
| 場所 | リンク先 | 書き方 |
|---|---|---|
| **本文の途中（文脈リンク）** | 関連する無料note 1〜2本 | 話の流れの中で自然に。「このときの話は、こちらに書いています」 |
| **本命noteへの誘導** | 本命note | 顕在層の記事：虫食い目次でしっかり／潜在層の記事：1〜2行で軽く、または顕在層の記事へ |
| **「次に読むなら」** | 無料note 2本 | 記事の最後に、読者の次の悩みに合う2本を選ぶ |
| **プロフィール** | 自己紹介（ハブ） | すべての記事の最後に |

### 文脈リンクの例
- E1の中で：「初デートでボロボロだった日のことは、自己紹介に書きました」→ H
- L2の中で：「実は、職場で話せても、女性の前ではダメでした。その話はこちら」→ E1
- E3の中で：「そもそも『つまらないと思われた』は、思い込みかもしれません」→ L1

### 新しい記事を出したら、やること
1. 新しい記事に、関連する既存記事へのリンクを入れる
2. **関連する既存記事の「次に読むなら」に、新しい記事を追加する**（網は、古い記事からも張り直す）
3. 自己紹介の「記事一覧」に追加する

### noteの機能で網を太くする
- **無料マガジン**「会話が苦手な人のための教科書（無料）」を作って、無料noteを全部入れる
- **自己紹介を固定記事**にする
- 記事の最後に**マガジンへのリンク**も入れる

## 6. 1本の無料noteの品質チェックリスト（公開前に必ず）

ぽにょさんの型（15）と、これまでのルールをまとめたものです。全部◯になってから公開します。

| # | チェック項目 | 基準 |
|---|---|---|
| 1 | タイトル | 読者の悩みの言葉（キーワード）が入っている。意外さか疑問がある |
| 2 | 冒頭3行 | 読者が今いる場面・思っていることを代弁している |
| 3 | 読む理由の予告 | 何がわかるか＋何分で読めるかを書いた |
| 4 | チェックリスト or 問いかけ | 読者が「自分のことだ」と思える |
| 5 | **新しさ** | 「4. 誰が何を持っているか表」で、この記事が主役のものが1つ以上ある |
| 6 | **重なりチェック** | ほかの記事の主役の研究・エピソードを、長く使っていない（言葉を検索して確認） |
| 7 | 体験 | さとるの体験は正本にあるものだけ。数字・心の声・五感があるか |
| 8 | 原因の断言 | 「〜だけ」で、才能のせいじゃないと言い切れている |
| 9 | 反論処理 | 「でも、それって〜でしょ？」に1回は答えている |
| 10 | **答えを出していない** | 有料の答え（3つの言葉、もしもプラン、場面別テンプレート、緊張のひと言、振り返り方）が出ていない |
| 11 | 今日やれる行動 | 読み終わってすぐできる小さな行動を1つ書いた |
| 12 | リンク | 文脈リンク1〜2本／本命noteへの誘導／次に読むなら2本／自己紹介 |
| 13 | 言葉のやさしさ | 高校生でもわかる言葉。むずかしい言葉は言い換えた |
| 14 | 締め | ポジティブ、または行動の呼びかけで終わっている |
| 15 | 文字数 | 3,000〜4,500字（5分前後で読める） |
| 16 | 見出し画像 | キャラクター・色・空っぽの吹き出しのルールどおり |

## 8. 既存の記事に、あとで足すこと
- **自己紹介（H）**：最後に「記事一覧」コーナーを作る（顕在・潜在で分けて並べる）
- **無料LP**：「次に読むなら」に E1・E3 を追加（公開後）
- **5つの思い込み（L1）**：「次に読むなら」に E1・L2 を追加（公開後）
- **本命note**：おわりのリンクに、自己紹介に加えて無料マガジンを追加
